# 🍕 Pizza Sales Analytics Dashboard

An interactive Power BI dashboard built to analyze pizza sales performance using KPI-driven reporting and business intelligence techniques.

## 📌 Project Overview

This project analyzes 50K+ pizza sales records to uncover insights related to:
- Revenue trends
- Customer ordering behavior
- Best and worst-selling pizzas
- Category-wise sales distribution
- Order patterns and performance metrics

The dashboard was designed to support data-driven business decisions through interactive visualizations and dynamic filtering.

---

## 🚀 Features

- KPI Cards for:
  - Total Revenue
  - Average Order Value
  - Total Orders
  - Total Pizzas Sold

- Interactive slicers and filters
- Drill-through analysis
- Category and size-based sales insights
- Monthly and daily trend analysis
- Best-selling vs worst-selling pizza analysis

---

## 🛠 Technologies Used

- Power BI
- SQL
- Power Query
- DAX
- Excel / CSV datasets
